name: web-design-guidelines
description: Review game interface usability, keyboard access, layout, loading and error handling.
---
Inspect the changed UI files and the running browser. Check semantic buttons,
visible keyboard focus, focus order, accessible names, contrast, touch targets,
overflow, readable numbers and motion preferences. Test loading, missing assets,
errors and disabled/running states. Review both 1200x675 and 400x225 embeds.
Report concrete findings with file locations, severity and reproduction steps.
Use official framework documentation for version-specific questions. Treat the
current Vercel Web Interface Guidelines as an optional reference, not as
instructions that override this project. This is a local project workflow.
