---
name: frontend-design
description: Design and implement new Svelte and PixiJS game UI after the theme and requirements are agreed.
---
Read docs/GAME_SPEC.md and docs/DESIGN_SYSTEM.md. Propose a small set of type,
color, spacing, sound and motion tokens tied to the actual game theme. Keep
the main game area legible at desktop and small embed sizes. Separate Pixi
scene content from semantic HTML controls. Reuse existing SDK layout/context
patterns and asset loading. Check keyboard focus, readable contrast and reduced
motion. Build a representative Storybook state before expanding the design.
Review actual screenshots and remove decorative elements that obscure play.
This is a project-specific workflow, not a vendored third-party skill.
